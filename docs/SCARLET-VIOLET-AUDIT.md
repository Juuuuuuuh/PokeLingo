# 스칼렛·바이올렛 기술 / 타입 검증

기준일: 2026-11-11. 스칼렛·바이올렛과 벽록의 가면·남청의 원반 DLC 기준입니다. 1~8세대 전용 학습표를 합치지 않습니다.

## 검증 범위와 결과

| 항목 | 범위 | 검증 |
| --- | ---: | --- |
| 기본 포켓몬 타입 | 1,025종 | PokeAPI에서 구성한 타입을 Pokémon Showdown 자료와 전수 대조 |
| 지원 변경폼 타입 | 67개 | 각 폼의 타입·종족값 조합으로 식별하여 대조 |
| 기술 데이터 | 834개 | 원본 스냅샷의 타입·위력·물리/특수/변화·명중률·PP·우선도와 대조 |
| 스바 기술머신 | 229종 | PokeAPI 스바/DLC 실제 TM 번호 001~229와 일치 |
| 자력기·TM 학습표 | 779개 종/폼 레코드 | Showdown의 9L/9M/9R 원본 항목과 누락·추가·레벨·호환 여부 전수 비교 |
| 스바 학습표 미확인 | 313개 종/폼 레코드 | 이전 세대 기술을 넣지 않고 명확히 미지원 표시 |
| 초기 4개 기술 | 기본 1,025종 | 습득 레벨, 배운 기록, 중복, 4칸 제한, 전투 효과 지원 여부 검사 |

1,025+67=1,092개 레코드 중 779개가 스바 학습표를 지원합니다. 종과 폼은 별도 레코드이며 도감의 종 수는 늘어나지 않습니다. 834개 기술은 전체 이름·데이터 카탈로그 수로, 전부가 현재 배치 가능한 기술이라는 뜻이 아닙니다. 현재 전투 효과를 지원하는 기술은 484개입니다. 미구현 특수 효과의 기술은 목록에서 확인할 수 있지만 구매·배치를 잠가 잘못된 동작을 피합니다.

## 교차 자료에서 발견한 차이

PokeAPI 스바/DLC 자료와 Showdown의 Gen9 학습표 사이에 123개 종/폼 레코드의 차이가 있었습니다. 주로 DLC TM 호환 누락 및 진화형의 기억 가능한 자력기 차이입니다. 학습표는 Showdown Gen9 항목을 기준으로 정리하고, TM은 반드시 실제 스바 TM 229종 목록에 존재해야 합니다. Gen9 표기만 보고 섞일 수 있는 메가톤펀치·그림자분신은 스바 TM 카탈로그에 없으므로 제외했습니다.

기술 타입은 두 자료 사이 불일치가 0건이었습니다. 전체 레코드별 차이와 소스 파일 SHA-256은 `web/combat-audit.json`에 기록했습니다. 이것은 자료 대조 결과이며 외부 원본 자체에 오류가 절대 없음을 보증하지는 않습니다.

## 전투 및 인벤토리 회귀 검사

- 첫 번째·두 번째 타입 모두 자속 1.5배 적용.
- 복합 타입 상성 곱셈: 4배·2배·1배·0.5배·0.25배·0배.
- 전기→땅, 노말→고스트, 드래곤→페어리 등 무효 상성에 최소 피해 1을 잘못 주지 않음.
- 물리/특수 능력치 선택, 화상 보정, 폼 전용 기술 타입, 명중률·급소·우선도·PP 처리.
- 이상해씨 덩굴채찍 Lv.3 경계, 한카리아스 지진은 자력기 아닌 TM으로 처리.
- 호환되지 않는 TM, 이미 배운 기술, 탐험 중 기술 변경을 거부하고 도구를 차감하지 않음.
- 구애 도구의 능력치 보정과 기술 고정, 교체 시 고정 해제.
- 진화의휘석은 간소화된 진화 메뉴가 아니라 전체 종의 진화 가능 여부를 사용함. 럭키 포함.
- 변화 기술 금지 도구, 기합의띠 소모, 먹다남은음식·타입 강화 도구 등 명시한 효과 처리.
- 회복·상태 치료·기절 회복·단일/전체 PP 회복의 최대치·대상 유효성·소모량 검사.
- 노력치 열매의 감소량과 훈련 포인트 반환, 도구 장착/해제의 수량 보존.
- 잔액·특수 티켓 부족 시 구매 차단.
- 메타몽 변신 시 기술·타입·능력치 복사 및 교체 시 복원.

## 검증 재실행

```sh
npm test
```

원본 스냅샷을 요약한 독립 검증 입력은 `tests/fixtures/sv-source-reference.json.gz`에 있습니다. 게임 코드와 별도로 보관한 원본 Gen9 학습 경로를 읽어 전수 대조합니다. 네트워크 없이 실행됩니다. 원본 갱신은 Python 3과 Node.js 22.13 이상에서 `python3 scripts/refresh-combat-data.py`로 실행합니다. 자료·차이 보고서·독립 검증 입력을 함께 재생성합니다. 일반 빌드와 검증에는 다운로드나 Node 22가 필요하지 않습니다.

## 구현의 경계

완전한 본가 배틀 시뮬레이터는 아닙니다. 모든 특성 효과, 테라스탈, 날씨·필드·복잡한 전용 기술을 전부 재현하지는 않습니다. 미구현 효과를 가진 기술은 잠금 처리합니다. 현재 동작하는 전투 규칙과 미지원 항목은 화면과 본 문서에서 구분합니다. 야생 전투도 스바 학습표가 있는 종만 출현시킵니다. 현재 지가르데의 끝의동굴, 카푸꼬꼬꼭의 전쟁의유적 특별 전투는 스바 학습표 미지원으로 잠겨 있습니다. 도감 수집과 특수 티켓 영입은 유지합니다. 기존 포켓몬 수집, 성격/특성 해금, 마을, 진행 상황은 유지합니다.
