# 초반 탐험과 밝은 화면 업데이트

## 초반 플레이

- 각 지방에서 정렬상 첫 번째 일반 탐험 한 곳씩, 총 9곳을 트레이너 Lv.1부터 엽니다. 다른 일반 지역 Lv.3, 패러독스 Lv.45, 준전설 Lv.55, 초전설·환상 Lv.60 조건을 유지합니다.
- 새로운 저장의 첫 파트너는 Lv.5입니다. 기존 파트너의 레벨·개체값·기술은 자동으로 덮어쓰지 않습니다.
- 신규·기존 저장 모두 출발 선물로 이상한사탕 4개와 상처약 3개를 한 번 지급합니다. `journeyWelcomeVersion`으로 중복 지급을 막습니다. 기존 종별 사탕 이전과 별도로 적용합니다.
- 첫 탐험의 미클리어 지역에서 파티 평균 레벨이 10 이하이면 일반 상대는 평균 레벨 -2, 마지막 일반 상대는 평균 레벨 -1로 조정합니다. 최소 Lv.1이며 재클리어·특별 조우·시설 전투에는 적용하지 않습니다.
- 첫 실제 목표 완료 보상에 100 EXP를 추가합니다. `firstQuestBonusClaimed`는 저장·재접속·날짜 변경 후에도 유지하며 취소하거나 중복 완료할 때 추가 지급하지 않습니다. 기본 목표 보상과 연속 보너스 계산은 유지합니다.
- 일일 출석 선물은 10코인 + 10 EXP입니다. 기존 날짜별 수령 기록으로 중복 수령을 막습니다. 이미 오늘 받은 기록을 소급해서 추가 지급하지 않습니다.
- 트레이너 레벨은 기존처럼 `1 + floor(EXP / 100)`입니다. 기존 저장의 레벨, 전설 입장 경계와 아르세우스의 전체 클리어 조건을 유지합니다.

## 화면

`theme.css`에서 흰색 카드·하늘색 바탕·몬스터볼 빨강/파랑을 사용합니다. 본문은 시스템 한글 글꼴 16px, 주요 설명과 컨트롤은 14px 이상입니다. 작은 날짜·보조 표시는 12~13px입니다. 기본 본문/흰색 대비 12.32:1, 보조 본문/흰색 5.41:1, 기본 빨간 버튼/흰 글자 4.55:1, 파란 버튼/흰 글자 5.86:1입니다.

홈은 탐험 출발 카드, 미션·탐험·연구소·상점 바로가기, 태초마을 지도, 오늘의 미션, 에너지 수첩, 파티와 포켓몬센터로 구성합니다. 기존 건물 클릭·마을 동료 배치·메뉴 토글·진행 중 전투·영입 보상 흐름을 유지합니다. 모바일은 한 열 구성으로 전환합니다. 도감·상점·기술·전투·센터도 같은 밝은 색상과 큰 글자를 사용합니다.

탐험의 긴 출현 규칙 설명은 펼쳐 볼 수 있고, 입장 레벨·에너지·티켓은 카드에 표시합니다. 첫 탐험 지역에는 추천 표시를 붙입니다.

## 검증

- `npm test`: 전체 기존 회귀 검사와 새 초반 플레이 검사를 실행합니다.
- `tests/journey-onboarding.cjs`: 세 스타터 각각 0 EXP·Lv.1 트레이너로 첫 탐험을 실제 턴 처리로 완료, 9곳 해금, 다른 단계 잠금, 선물·첫 목표·출석 보상 중복 방지, 재접속, 기존 전설 레벨 조건과 홈 이동 경로를 확인합니다.
- 새 스타일의 괄호·문자열 균형 및 주요 텍스트 색상 대비를 확인했습니다.
- 현재 환경에 Sites의 `cua_repl.js` 브라우저 도구가 없어 화면 캡처·실제 브라우저의 배치 검증은 수행하지 못했습니다.
