# 전국도감 탐험 수집 감사

## 결론

현재 탐험만으로는 도감을 완성할 수 없습니다. 출현 후보의 이론적 합집합과 실제 한 저장에서의 포획 가능성은 다릅니다. 이 검사는 출현표 수정 없이 현재 코드를 읽고 수행했습니다.

- 구현 데이터: No.1~1025, 마지막 종은 복숭악동입니다. 1026번째 종 데이터는 없습니다.
- 실제 일반 조우 212종 + 특별 마지막 조우 103종 − 중복 1종 = **314종**.
- 모든 후보를 얻었다고 가정하고 구현된 진화 경로를 전부 확장한 낙관적 상한: **431종**, 누락 **594종**.
- 첫 동료 한 종(이상해씨 또는 파이리 또는 꼬부기)을 추가하면 낙관적 상한 434종. 세 시작 선택지를 모두 합친 분석상 합집합은 440종이며, 한 저장에서 세 스타터를 전부 지급한다는 뜻은 아닙니다.
- 일반 지역 65곳은 최초 클리어에만 포켓몬 1마리를 지급합니다. 반복 클리어에는 포켓몬 보상이 없습니다. 전투에서 만난 일반 야생 포켓몬을 직접 잡는 기능도 없습니다.
- 특별 영입 없이 탐험에서 빠진 특별 포켓몬: No.789 코스모그, No.790 코스모움, No.1016 기로치.
- 일반 스카우트 920종과 특별 영입 105종까지 포함하면 데이터상 1025종 모두 수집 경로가 있습니다. 자원·레벨·반복 플레이는 필요하며, 이것은 탐험만으로 완성 가능하다는 뜻이 아닙니다.

## 누락 원인

1. 일반 출현표에 모든 종과 진화 계열이 배치되어 있지 않습니다. 스타터·화석·베이비와 여러 일반 종이 탐험 후보에서 빠져 있습니다.
2. 스바 학습표가 없는 일반 종은 일반 전투 후보에서 제외됩니다. 예를 들어 상록숲 원본 목록의 캐터피·뿔충이는 실제 전투 후보에서 빠집니다. 특별 포켓몬은 관찰 조우로 수집하는 경로가 있지만 일반 종에는 그와 같은 경로가 없습니다.
3. 지역의 새 세대 일반 후보가 3종 이상이면 이전 세대 후보는 실제 추첨에서 제외됩니다. 원본 pool에 이름이 있다는 사실만으로 실제 출현을 보장하지 않습니다.
4. 일반 지역의 일회성 포켓몬 보상 때문에 후보를 늘리는 것만으로도 도감 완성이 보장되지는 않습니다.
5. 최근 요청한 팔데아 사당 목록에는 기로치가 없어서 현재 특별 영입에서만 얻을 수 있습니다. 코스모그·코스모움도 탐험의 최종 전설 목록에서 제외된 상태입니다.

## 검증 범위와 제한

현재 코드의 실제 가중 추첨 함수를 통해 모든 일반 후보가 추첨 가능한지 확인했습니다. 실제 클리어 보상 함수를 두 번 호출해 최초/반복 보상 차이를 검증했습니다. 레지기가스·랜드로스의 선행 포켓몬은 입장 조건 없는 반복 가능한 특별 탐사에서 확보할 수 있어 조건이 서로 순환하지 않습니다. 진화 확장은 레벨 100과 구매 가능한 모든 진화 도구를 허용한 상한이며, 실제 저장에서의 분기 진화·첫 보상 추첨·시간·재화까지 자동으로 완성했다는 검사는 아닙니다. 브라우저 시각·클릭 검증은 수행하지 않았습니다.

## 탐험만으로 완성하려면 필요한 수정

- 모든 종에 탐험 직접 영입, 관찰 조우, 알/화석/스타터 보상 또는 실현 가능한 진화 경로를 배정해야 합니다.
- 일반 탐험도 반복 수집 경로를 제공하고, 미등록 종을 얻을 기회를 보장해야 합니다.
- 스바 미지원 종은 임의 기술로 전투시키기보다 별도 관찰·구출 보상 같은 수집 경로가 필요합니다.
- 기존 지정된 전설 지역은 보존하면서 코스모그·코스모움·기로치의 수집 경로를 별도로 보완해야 합니다.
