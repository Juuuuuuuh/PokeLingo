# 도구 이미지와 폼 변경 가격

상점의 116개 일반 상품과 229개 기술머신 모두 실제 도구 이미지를 표시합니다. 가방·지니는 도구 선택·구매 확인에도 같은 이미지를 사용합니다. 세트 상품은 구성품 중 최대 세 개 이미지를 카드에 표시하고 전체 구성품 수를 함께 표시합니다.

## 이미지 출처와 배포

- 출처: [PokeAPI sprites](https://github.com/PokeAPI/sprites)
- 고정 커밋: `1b3b7c0a538dd2226ae08d0d2f8955125075bbd4`
- 원본 경로: `sprites/items/*.png`
- 실제 서비스 파일: `web/assets/items/*.png` 173개 (334,140 bytes)
- 상품별 연결: `web/item-art.js`의 `ITEM_ART`, `TM_ART`
- 재다운로드·파일 검증: `python scripts/download-item-art.py`

스프라이트는 서비스와 함께 배포하므로 플레이할 때 외부 이미지 서버에 의존하지 않습니다. 이미지 데이터는 포켓몬 팬 프로젝트의 기존 비상업적 에셋 사용 맥락에 따라 사용하며, 원본 권리는 각 권리자에게 있습니다. 원본 에셋을 자체 제작한 것으로 주장하지 않습니다.

## 폼 변경 도구 단가

| 구분 | 도구 | 코인 |
|---|---|---:|
| 일반·준전설 | 로토무카탈로그·꽃꿀 세트·비추는거울·가면 세트·메모리 세트 | 25 |
| 초전설·환상 | 운석·큰금강옥·큰백옥·큰백금옥·그라시데아꽃·굴레의항아리·카세트 세트 | 250 |
| 합체·플레이트 세트 | 유전자쐐기·네크로플러스 세트·유대의고삐·플레이트 세트 | 400 |

모든 폼 변경 도구는 한 번 구매하면 영구 보유합니다. 기본폼 복귀는 무료이며 기존 구매 도구는 추가 결제 없이 계속 사용합니다. 이번 조정에는 특수 티켓을 추가로 요구하지 않습니다. 구매 카드·확인창·실제 차감은 `ITEMS[].price`를 함께 사용합니다.

일반 스카우트 100코인, 이상한사탕 60코인과 비교하여 고가 폼 도구는 스카우트 2.5~4회에 해당하는 목표입니다. 반복 폼 변경마다 비용을 청구하지 않으므로 해금 가격에 무게를 둔 초기 밸런스입니다. 진화석 20코인·연결의끈 30코인 및 회복·육성 도구 가격은 유지합니다.

## 검증

- 모든 일반 상품과 TM의 이미지 매핑 및 로컬 PNG 존재·헤더 확인.
- 173개 PNG 디코딩·크기·투명 이미지 여부 검사.
- 각 상점 카테고리에서 모든 상품의 이미지 마크업 표시 확인.
- 배포 Worker의 전체 도구 이미지 응답 200·image/png·PNG 헤더 확인.
- 초전설·환상 소비 종을 기준으로 가격 대상 11개가 빠짐없이 적용되는지 확인.
- 잔액 부족 시 차감 없음, 정확한 250/400 차감, 중복 영구 도구 구매 차단, 기존 저장의 도구·잔액 유지 확인.
- 기존 기술·진화·합체·탐험·PWT 테스트 유지.

브라우저 시각·클릭 검증은 현재 실행 환경에서 사용할 수 없어 수행하지 않았습니다. HTML 렌더링 및 Worker 응답 검증은 실제 브라우저 검증과 구분합니다.
