# 본가 참고 배틀 화면

## 배치와 조작

야생 탐험·체육관·PWT가 하나의 배틀 화면을 사용합니다. 상대 포켓몬은 위쪽 전면, 플레이어 포켓몬은 아래쪽 후면에 배치합니다. 상대와 내 포켓몬의 이름·레벨·타입·상태·HP바를 표시하고, 내 포켓몬은 HP 숫자도 표시합니다. HP가 절반 이하이면 노랑, 20% 이하이면 빨강으로 표시합니다. 존재하지 않는 성별이나 개별 EXP를 임의로 표시하지 않습니다.

기본 명령은 싸운다·포켓몬·가방·도망간다입니다. 싸운다에서 현재 배치한 기술 4칸을 표시하고 이름·타입·분류·위력·명중·현재/최대 PP·타입 상성을 보여줍니다. 빈 칸, PP 부족, 지니는 도구 제한은 선택할 수 없습니다. 사용 가능한 기술이 모두 없으면 발버둥을 표시합니다. 변화 기술의 성공을 대미지 상성으로 단정하지 않으며 상성 표시는 기존 18타입 계산을 사용합니다.

명령·기술·교체 화면을 열거나 취소해도 턴이나 PP는 소모하지 않습니다. 기술을 누르면 기존 전투 엔진으로 실행하고 기본 명령으로 돌아옵니다. 포켓몬 화면의 일반 교체는 상대가 한 번 행동하며, 기절 시 강제 교체는 상대의 추가 턴 없이 처리합니다. 강제 교체는 취소할 수 없습니다. Escape 키로 기술·일반 교체 화면을 닫을 수 있습니다.

PWT 가방 사용 금지와 트레이너전 도망 금지는 화면에 표시합니다. 체육관/PWT의 도전 포기는 별도 버튼으로 기존 패배·보상 규칙을 적용합니다. 야생의 도망간다는 기존 탐험 중단 확인창을 사용하며, 본가의 확률 도주 계산을 새로 구현한 것은 아닙니다. 갈림길·쉼터·승리 보상·관찰 조우의 기존 흐름도 유지합니다.

이번 변경은 본가의 화면 배치와 명령 흐름을 참고한 팬게임 UI입니다. 모든 본가 특성·배틀 효과·테라스탈·확률 도주를 새로 구현했다는 뜻은 아닙니다.

## 이미지

내 포켓몬 후면 이미지 1,054개(전국도감 1~1025종 + 지원 폼 중 29개)를 로컬 배포합니다. 후면이 없는 별도 폼은 해당 폼의 기존 전면 이미지를 사용합니다. 배포 후 외부 이미지 서버에 의존하지 않습니다.

- 출처: [PokeAPI sprites](https://github.com/PokeAPI/sprites)
- 고정 커밋: `c0542f7c51215d9672439012838c99f520596cbd`
- 원본 경로: `sprites/pokemon/back/*.png`
- 매핑: `web/battle-art.js`
- 재다운로드: `python scripts/download-battle-art.py`

## 검사

명령 전환·취소 시 HP/PP 보존, 실제 공격의 PP 소모, 타입 상성·변화 기술 표시, 빈 PP 발버둥, 강제 교체, PWT 도구 사용 금지, 전 종 후면 PNG 존재·디코딩·투명 이미지 여부 검사를 추가했습니다. 기존 전투·학습·진화·탐험·대회 테스트도 유지합니다.

배포 후 PC·모바일 브라우저로 명령·기술·교체·가방 화면을 확인했습니다. 클릭 뒤 포커스가 본문으로 이동하는 경우에도 Escape 취소가 동작하도록 문서 수준에서 취소 키를 처리합니다. 대화창이 열린 동안은 기본 대화창 닫기와 충돌하지 않습니다.
