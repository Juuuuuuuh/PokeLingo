# 체험 모드와 콘텐츠 메뉴

## 메뉴

하단 8개 콘텐츠 메뉴는 기본적으로 숨깁니다. 헤더의 메뉴 버튼으로 펼치며 콘텐츠 선택 또는 Escape 키로 닫습니다. 선택 시 콘텐츠 페이지로 바로 이동합니다. 폰에서는 4열 2행으로 표시합니다.

마을의 건물은 이미지·이름 영역 전체가 버튼이며 기존 목적지로 연결합니다. 도감 기록과 추가된 도감·파티·체육관/PWT 바로가기도 버튼으로 직접 연결합니다.

## 체험

- `?demo=explore`: Lv.12 예시 파티로 달맞이산 실제 수동 전투에 진입.
- `?demo=tasks`: 예시 미션 2개를 준비한 퀘스트 게시판.
- `?demo=home`: 체험용 태초마을.

체험도 동일한 보상·배틀·PP·타입 계산과 화면을 사용합니다. 체험 전용 보상이나 승리 보장 로직은 없습니다. 체험 파티·초기 재화만 예시로 지급하며, 예시 목표는 실제 AI 평가가 아닌 기존 기본 계산을 사용합니다.

저장 키는 `growth-expedition-demo-v1`로 실제 게임의 `growth-expedition-v1`과 분리합니다. 체험 초기화는 체험 키만 삭제합니다. 내 게임으로 링크는 쿼리 없이 돌아가 실제 저장을 다시 불러옵니다. 기존 저장에 예시 미션·몬·재화를 추가하지 않습니다.

## 검사

메뉴 기본 숨김, 펼치기, Escape, 콘텐츠 이동 시 닫기, 마을 연결, 체험 저장 분리, 체험 목표 보상, 실제 PP 소모 전투, 체험 초기화 후 실제 저장 유지 검사를 추가했습니다. 기존 전투·수집·상점 검사도 유지합니다.

배포된 실제 페이지를 설치된 Chromium의 헤드리스 실행으로 확인했습니다. 예시 미션 신규 등록·기본 평가·보상 지급, 실제 기술 선택과 PP 소모, 메뉴 펼치기·콘텐츠 선택 후 닫기, 홈 건물·파티 직접 이동을 확인했습니다. 모바일 메뉴 높이 문제를 발견해 높이 자동/2행 제한을 적용했습니다. 공유 데스크톱 조작 도구는 연결되지 않아 같은 로그인 탭의 화면을 캡처한 것은 아니며, 별도 브라우저의 체험 모드 캡처입니다.
