# 스바 기술 도구·기술머신 상점

## 목록과 사용

상점의 **기술 도구** 탭에 하트비늘과 **TM001~TM229 전체**를 함께 표시합니다. 예전 내부 탭 이름 `기술머신`도 같은 목록으로 처리하여 이전 코드 경로를 유지합니다. TM 번호 순으로 정렬하며 번호(`97`, `097`, `TM097`), 기술 이름, 타입으로 검색할 수 있습니다.

범위는 팔데아 TM001~171, 벽록의 가면 TM172~201, 남청의 원반 TM202~229입니다. 모든 상품은 타입별 로컬 이미지를 사용하며 기존 가방 키 `tm-기술ID`를 유지합니다. 구매 후 **파티 → 기술 확인하기 → 기술머신**에서 해당 종·폼의 스바 학습표에 맞춰 배웁니다. TM은 기술 슬롯 확정 시 한 개 소모합니다. 이전 사용자 요청에 따라 습득 기록과 하트비늘을 사용하는 떠올리기 규칙은 유지합니다.

현재 전투 효과 지원 TM은 149종입니다. 나머지 80종도 목록·가격을 표시하지만 구매는 잠가 두었습니다. 미지원 효과를 임의의 즉시 공격으로 바꾸지 않습니다. 특히 공중날기의 2턴 효과와 바다회오리의 지속 구속 효과는 아직 구매 잠금 대상입니다. 이는 229종 전부를 지금 사용할 수 있다는 뜻이 아닙니다.

## 비전머신 정책

스칼렛·바이올렛에는 별도 비전머신 상품이 없습니다. 과거 비전기였던 기술도 스바의 TM 번호와 배우는 종을 따릅니다.

| 기술 | 스바 번호 | LP | 코인 | 현재 구매 |
|---|---|---:|---:|---|
| 폭포오르기 | TM077 | 8,000 | 100 | 가능 |
| 공중날기 | TM097 | 5,000 | 70 | 전투 효과 준비 중 |
| 파도타기 | TM123 | 10,000 | 120 | 가능 |
| 바다회오리 | TM208 | 800 | 30 | 전투 효과 준비 중 |

풀베기·괴력·플래시·바위깨기·다이빙·락클라임을 가상의 9세대 HM 상품으로 추가하지 않습니다. 탐험 입장은 기존 레벨·파티·포획 조건을 사용하며 특정 비전기 배치를 요구하지 않습니다. 코라이돈·미라이돈의 원작 필드 라이드는 별도 구현한 것이 아닙니다.

## 가격 환산

원본 LP 제작비는 [Serebii 스바 TM 목록](https://www.serebii.net/scarletviolet/tm.shtml)을 확인하고, 229개 TM 번호·기술 식별자는 기존 PokeAPI/Showdown 스바 데이터와 전부 대조했습니다. 원본 숫자와 정규화된 기술 식별자는 `data/sv-tm-lp-costs.json`에 저장했습니다. 원문 설명이나 지도·위치 텍스트는 복제하지 않습니다.

이 게임은 LP·드롭 재료를 별도로 추가하지 않고, 다음 코인 환산식을 사용합니다.

`가격 = 준비비 20코인 + 5 × ceil(원본 LP / 500)`

준비비는 별도 재료 수집을 대신하는 고정 비용이며 실제 스바 가격의 일부라는 뜻은 아닙니다. LP가 같은 TM은 같은 코인 가격이며, LP가 높을수록 가격이 내려가지 않습니다.

| 원본 LP | 코인 |
|---:|---:|
| 200 / 400 | 25 |
| 800 | 30 |
| 1,500 | 35 |
| 3,000 | 50 |
| 5,000 | 70 |
| 8,000 | 100 |
| 10,000 | 120 |
| 12,000 | 140 |
| 14,000 | 160 |
| 15,000 | 170 |

일반 스카우트 100코인·이상한사탕 60코인과 비교하여, 저비용 TM은 목표 보상 일부로 사고 고비용 TM은 모아서 사도록 정했습니다. 표시 가격·구매 확인창·실제 차감은 모두 `TM_CATALOG[].price`를 사용합니다. 기존 보유 TM의 수량·배운 기술·코인은 추가 차감 없이 유지됩니다.

## 검증

- 번호 1~229의 중복·누락 없음 및 원본 LP·기술 식별자 전수 대조.
- 기존 데이터 생성기를 별도 임시 체크아웃에서 실행해 같은 가격·카탈로그가 재생성되는지 확인.
- 기술 도구 탭에 하트비늘과 229개 TM 모두 표시, 검색·번호 정렬·DLC 구분 확인.
- 단가의 범위 25~170 및 LP 순서에 따른 단조 증가 확인.
- 실제 구매·잔액 부족·구매 잠금·TM 소모·학습 기록 테스트.
- 기존 기술 타입·자력기·TM 호환성·진화·탐험·PWT 검사 유지.

브라우저 시각·클릭 검증은 현재 환경 제한으로 수행하지 않았습니다.
