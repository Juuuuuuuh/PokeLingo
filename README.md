# 성장의 탐험대

개인 성장 활동을 포켓몬 수집과 탐험으로 연결하는 비공개 팬게임 프로토타입.

## 실행 및 검증

소스는 `web/`, 서버 API는 `worker/api.mjs`에 있습니다. 의존성 설치는 필요하지 않습니다.

```sh
python scripts/build.py
node tests/game.cjs
node tests/worker.mjs
```

빌드 결과는 Cloudflare Worker ESM인 `dist/server/index.js`입니다. 정적 화면과 1,025종의 로컬 스프라이트를 포함합니다. `.openai/hosting.json`의 기존 Site ID와 접근 권한을 유지합니다.

## 픽셀 마을 인터페이스

홈은 건물을 직접 선택하는 픽셀 마을입니다. 포켓몬의 집은 실내/배치, 퀘스트 게시판은 목표, 연구소는 영입, 상점은 진화 도구, 탐험의 문은 9개 지방 탐험으로 연결됩니다. 하단 도크로 도감과 파티에도 접근할 수 있습니다. 기존 v1 저장 키와 진행 상황을 유지합니다.

기본폼 이상해씨·파이리·꼬부기·피카츄·이브이는 PMDCollab/SpriteCollab의 원본 방향별 걷기 프레임을 CSS로 표시합니다. 그 외 포켓몬과 변경폼은 기존 스프라이트로 이동합니다. 움직임 줄이기 접근성 설정을 존중합니다. 픽셀 마을/건물/실내 그래픽은 자체 작성한 SVG이며 외부 게임 화면의 복사본이 아닙니다.

## 스바 기술과 도구

기술 4칸 배치, 포켓몬 레벨에 따른 자력기 학습 선택, 호환 검사 후 사용하는 소모성 TM 229종을 지원합니다. 기술머신은 상점에서 구매합니다. 물리/특수, 위력, 명중률, PP, 우선도, 자속 1.5배 및 복합 타입 상성을 전투에 반영합니다. 포켓몬별 HP·PP를 관리하며, 전투 중 도구 사용이나 일반 교체에는 한 턴을 사용합니다.

상처약·음료·상태 치료·기절 회복·PP 회복·지니는 도구·노력치 감소 열매를 상점과 가방에서 사용할 수 있습니다. 진화 도구는 20~30코인을 유지합니다. 구애 도구 등 일부 강력한 도구는 특수 티켓도 필요합니다. 가격은 목표 보상과 스카우트 100코인을 기준으로 한 초기 밸런스이며 실제 플레이에 따라 조정할 수 있습니다.

기준은 **스칼렛·바이올렛 + DLC**입니다. 이전 세대 기술을 섞지 않습니다. 자료 대조 결과 및 지원 한계는 [검증 문서](docs/SCARLET-VIOLET-AUDIT.md)를 참조하세요. 미확인 학습표와 미구현 특수 효과는 명확히 표시하고 배치를 제한합니다.

## 태초마을 · 기술 기억 · 지방별 탐험

마을 이름은 **태초마을**입니다. `능력치를 본다`, `기술 확인하기`, `이상한사탕 사용`으로 동료를 관리합니다. 한 번 배운 기술은 진화 후에도 기록과 사용 슬롯에 남습니다. 네 칸이 찼을 때는 잊고 배우기/배우지 않기를 직접 선택하며, 잊거나 넘어간 기술은 하트비늘로 떠올립니다. 도구는 선택 확정 시에만 소모합니다.

레벨업은 공용 **이상한사탕**으로 진행하고 스바식 능력치 변화를 여섯 항목으로 표시합니다. 기존 종별 사탕은 이전되며, 탐험 보상도 자동 레벨업 대신 이상한사탕으로 지급합니다.

탐험은 관동~알로라 각 10곳, 가라르·팔데아 각 13곳으로 **총 96곳**입니다. 대표 이미지는 해당 세대에서 처음 등장한 포켓몬만 사용합니다. 일반 지역 뒤에 준전설 Lv.55, 초전설 Lv.60 지역을 배치하고, 특별 후보는 해당 세대의 동일 등급 전체로 구성합니다. 해당 세대 일반 후보가 충분하면 기존 세대를 섞지 않으며, 부족할 때만 지역의 기존 세대 후보로 보충합니다. 가라르의 백마/흑마 버드렉스, 팔데아의 사당/패러독스 구역도 구분합니다.

자세한 정책과 테스트 범위: [기술 기억·성장·지방별 탐험](docs/PROGRESSION-AND-REGIONS.md).

## 기능

- 전국도감 No.1~1025, 한국어 이름, 복합 타입, 종족값, 일반/숨겨진 특성, 세대/보유/검색/페이지 탐색
- 홈 하우스 6마리 배치, 움직임 줄이기 접근성 설정 지원
- 종별 한 마리 보유, 중복 박사 전송 시 성격/특성/발견 폼 해금, 이상한사탕 획득, 능력치별 최고 개체값 누적, 공격/스피드 0 기록 보존
- 성격 및 개체값/노력치를 실제 능력치와 간단한 탐험 전투에 반영
- 1~9세대 지방별 96개 야생 서식지, 특수 조우, 최초/반복 보상 분리
- 412개 기본폼 레벨/아이템 진화 규칙, 연결의끈 통신진화, 67개 도구 기반 변경폼, 저렴한 도구 상점
- 목표별 난이도/중요도/노력 평가, 평가 결과 확인 후 등록 및 보상 고정
- 브라우저 로컬 저장, v1 저장 데이터 이전, JSON 백업/복원

## 실제 AI 평가 연결

Sites 비밀키 설정 지침에 따라 OpenAI Developers 플러그인의 `openai-platform-api-key` 스킬로 키를 준비한 뒤 Sites 런타임 비밀키 `OPENAI_API_KEY`에 설정합니다. 키를 소스, 브라우저 코드, 백업, 채팅에 넣지 않습니다. 선택적 런타임 값 `OPENAI_MODEL`의 기본값은 `gpt-4.1-mini`입니다.

`POST /api/evaluate-goal`은 서버에서만 OpenAI Responses API를 호출하고 구조화된 점수로 보상을 계산합니다. 사용자 데이터는 `store:false`로 전달합니다. 비밀키가 없으면 명확한 503 응답을 반환하며 사용자가 별도 버튼으로 기본 규칙 계산을 선택할 수 있습니다. 기본 계산을 AI라고 표시하지 않습니다. `GET /api/ai-status`는 연결 설정 여부만 반환합니다.

## 특별 조우 레벨 조건

모든 세대에서 **트레이너 레벨**을 기준으로 준전설(울트라비스트 포함)은 Lv.55, 초전설과 환상은 Lv.60부터 특별 조우 및 특수 티켓 영입을 할 수 있습니다. 포켓몬 파티 레벨과는 별개입니다. 일반 스카우트 목록에서는 이들을 제외하며 레벨 미달 시 티켓을 차감하지 않습니다. 기존에 얻은 포켓몬은 유지합니다. 이전 버전에서 시작한 미완료 특별 탐험이 새 조건에 맞지 않으면 종료하고 사용한 티켓을 돌려줍니다. 이미 완료한 탐험의 미수령 보상은 해당 레벨이 될 때까지 보관합니다.

## 현재 범위

종 데이터는 PokeAPI 기준 1,025종입니다. 변경폼은 종 수에 중복 가산하지 않습니다. 지역폼/메가진화/일부 전용 배틀폼 및 복잡한 기술/특성 효과는 전체 구현이 아닙니다. 특성 수집과 선택은 지원하지만 개별 특성의 전투 효과는 후속 범위입니다. 진화는 화면에 표시한 레벨/도구 조건으로 간소화하여 성별, 시간, 특정 교환 상대, 회전 등의 조건을 생략합니다. 융합폼은 파트너의 도감 등록도 요구합니다.

탐험 장소는 원작 서식지를 바탕으로 선별했지만 전체 출현표/날씨/확률의 복제는 아닙니다. 특수 장소의 일반 포켓몬은 인근 접근로를 포함합니다. 탐험은 직접 이동하는 타일맵이 아닌 5구역 전투/선택형입니다. 특수 티켓은 실패/중단 시 환급됩니다.

진행 기록은 기기 간 동기화되지 않습니다. 보상 검증도 개인용 로컬 모델이며 멀티플레이 부정행위 방지 시스템이 아닙니다. AI 서버 경로는 자동 테스트에서 모의 응답으로 검증하며, 실제 API 키가 연결되기 전에는 실서비스 모델 호출이 검증되지 않습니다.

## 체육관·PWT와 자동 탐험 (0.6)

미클리어 지역은 직접 전투, 직접 클리어한 지역만 실제 전투 엔진으로 자동 전투합니다. 목표 완료로 얻는 에너지를 소모합니다. 체육관은 Lv.8, PWT는 Lv.20·도감 10종·체육관 3승에 열립니다. 지방별 3라운드 대회와 첫 우승 트로피를 제공합니다. 세부 경제·전투 규칙은 `docs/PROGRESSION-AND-REGIONS.md`를 참고하세요. 저장은 현재 브라우저에 유지됩니다.

## 특별 출현 목록 수정

준전설·초전설·환상 지역 카드에 해당 세대의 전체 후보를 이미지와 이름으로 표시합니다. 1~9세대 환상 탐사 9곳을 추가해 총 105곳입니다. 준전설 Lv.55·초전설 및 환상 Lv.60 조건을 유지합니다. 버드렉스 기본·백마·흑마 모두 출현합니다.
